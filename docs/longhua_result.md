# 龙华区 v4.37 结果

数据规模：629个小区、44所学校、27,676个候选关系。五折保持原空间组和观察掩码；每折测试标签在锚点构造、训练和校准前清空；全部预测冻结后评分。

| 方法 | 精确率 | 召回率 | F1 |
|---|---:|---:|---:|
| 非 Gold 规则 | 78.78% | 40.91% | 53.85% |
| 空间监督基线 | 70.15% | 79.61% | 74.58% |
| 直接预测、单验证块校准 | 80.87% | 81.54% | 81.21% |
| **直接预测、四折合并校准** | **85.97%** | **86.09%** | **86.03%** |

固定 holdout 为86.82%精确率、88.89%召回率。

这是已经多轮开发过的 `SUPERVISED_DEVELOPMENT` 结果，不是新盲测。五折汇总超过双80，但第1折为79.49%精确率、77.50%召回率，没有满足“所有折均双80”或“每折相对原规则两项都不下降”。仓库不得把汇总结果改写成逐折稳定性结论。

模型不要求完整的小区—社区/居委会对应表。社区信息存在时可以作为额外数值特征；缺失时仍由小区名称、坐标、道路/文字证据和训练关系锚点完成预测。
