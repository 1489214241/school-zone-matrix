# Gold 隔离协议

## 允许进入预测侧

- 同年官方学区文字描述；
- 独立获取的学校和小区目录；
- 小区名称、地址、坐标、道路和OSM信息；
- 经过来源审计的社区或居委会辅助信息；
- 当前确定的训练折关系标签。

## 禁止进入预测侧

- 测试折关系标签；
- 官方学区地图边界、地图点落区结果及其派生距离；
- 由测试错误清单定向补充的别名、候选或阈值；
- 利用 Gold 删除学校、小区或候选关系；
- 把 Gold 未知关系当作负例。

## 执行顺序

1. 固定年份、学段、实体全集、候选笛卡尔积、空间组和外层折。
2. 每个外层折在训练前清空整个测试空间组的 `label` 和 `observed`。
3. 训练锚点特征采用内部交叉拟合，当前关系不能使用自身标签。
4. 模型和解码参数只从外层测试折之外的合并校准预测选择。
5. 输出全量预测并记录 SHA-256。
6. 独立评价命令验证哈希后读取 Gold。
7. 首次评分后的改动属于新的开发实验，不能继续声称同一次盲测。

本仓库从程序层面分离 `crossfit-predict` 与 `evaluate`。正式论文实验还应使用权限隔离的目录或独立进程，使预测进程无法读取测试 Gold 原文。
